# Sinkronisasi State URL dan History Stack Browser

Untuk menjaga kesinambungan penjelajahan katalog (preserving scroll position dan grid state) sekaligus mendukung deep linking dan navigasi tombol Back native browser, kami menggunakan query parameters (`tag`, `q`, `page`, `prompt`) yang disinkronkan ke browser History API pada galeri utama, bukan Next.js route transitions penuh. Modal Viewer dikendalikan oleh parameter `?prompt=:id` dengan mekanisme *History Priming* pada saat direct load (menyisipkan entri `/` ke stack) agar navigasi mundur tidak melempar pengguna keluar dari situs. Debounce pencarian memperbarui URL via `replaceState` sedangkan penekanan Enter, perpindahan Tag, dan pagination menggunakan `pushState`. Keputusan ini menghasilkan navigasi yang instan dan riwayat browser yang bersih tanpa tumpukan entri ketikan sementara.
